# 💰 Expense Tracker

A modern and responsive Expense Tracker web application built using HTML, CSS and JavaScript.

The application allows users to manage their daily expenses, search expenses, filter them by category and store data permanently using LocalStorage.

## 🚀 Features

- ➕ Add new expenses
- 🗑️ Delete expenses
- 🔎 Search expenses by name
- 🏷️ Filter expenses by category
- 💰 Calculate total expenses
- 📊 Display total transaction count
- 💾 Store expense data using LocalStorage
- ✅ Form validation
- 📱 Fully responsive design
- 🎨 Modern and clean user interface
- 🖼️ Finance-themed hero section
